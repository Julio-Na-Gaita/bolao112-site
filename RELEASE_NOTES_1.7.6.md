# Bolão 112 FC — Versão 1.7.6 Estável

## Status

Versão estável da fase de melhorias administrativas, visuais e de experiência do usuário da versão web/PWA.

## Principais melhorias consolidadas

### Home e confrontos
- Botão Prazos implementado.
- Linha do tempo de prazos implementada.
- Letreiro corrigido para não exibir HTML cru.
- Seções fixas de confrontos protegidas.
- Seções visuais customizadas funcionando.

### Ranking
- Visual do ranking refinado.
- Modo Compacto / Detalhado.
- Top 3 destacado.
- Supermedalha a partir de 10 medalhas iguais.
- Modal de informações do ranking melhorado.

### Perfil e Scout
- Sala de Troféus preservada.
- Scout Premium / Ver Estatísticas refinado visualmente.
- Cards, gráfico, últimos palpites e desempenho por competição melhorados.

### Porquinho e premiação
- Tela de acumulado/pote refinada.
- Divisão prevista da premiação adicionada:
  - 1º lugar: 40%
  - 2º lugar: 25%
  - 3º lugar: 18%
  - 4º lugar: 10%
  - 5º lugar: 7%

### Regulamento
- Painel admin de Regulamento implementado.
- Modal público de regras corrigido.
- Tela obrigatória de aceite corrigida.
- Compatibilidade com regras ativas/inativas.

### Painel Admin
- Resumo Operacional refinado.
- Histórico Admin corrigido.
- Criação, Baixa Rápida e Limpeza mantidas.
- Gestão Visual adicionada.

### Gestão Visual
- Sections, Banners e Enquetes implementados.
- Aba Aparência adicionada.
- Presets de tema, fontes e backgrounds implementados.
- Background global e por tela implementado.

## Observações

- A versão web/PWA está priorizada.
- A versão Android antiga segue como referência histórica, mas as melhorias principais foram portadas para a web.
- Esta versão deve servir como ponto seguro de restauração antes de novas melhorias de engajamento.
